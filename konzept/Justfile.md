# Die Justfile Anweisungen 

just install -> programm und alle dependencies installaieren

just preprocess -> alle raw daten in eine annotierte Form bringen

just setup -> mit setup ui soll man bundesland und weitere Kompetenz (z.B. hinterlegte EU Digi Komeptenzen auswählen) 

just run -> installieren, preprocessen und starten 


Anmerkung: Perspektivisch in der Aufsetzungsanleitung mit einem Terminal befehl auf windows/ linux /macos anweisung geben, wie man auch just installiert bzw copy paste machen kann eine befehlsequenz
