# Einzelstundenplanung

Ein `scheduled_lesson` kann auf eine `sequence_lesson` und einen bestehenden `WorkshopPlan` verweisen. Der bestehende Plan bleibt der detaillierte Stundenverlaufsplan mit Materialien, Präsentation und Phasen.

Der Ablauf ist: Lehrplanbezug → Reihe → Sequenzstunde → geplanter Termin → detaillierter Verlaufsplan → Durchführung → Reflexion. Workshops und Einzelplanungen ohne Reihenbezug bleiben voll funktionsfähig.

Beim Anlegen aus einer Sequenzstunde werden Termin, Titel, Ziel, Lehrplanbezug und ausgewählte Materialien bewusst übernommen; es entstehen keine stillen Rückkopplungen zwischen unabhängigen Plänen.
